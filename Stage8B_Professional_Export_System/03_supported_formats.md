# Stage 8B — Supported Formats

Six formats ship in Stage 8B. Every one renders from the same canonical
`ReportModel`; the modal shows the label, extension, estimated size, description,
and recommended use for each, with a Download button.

| # | Format | Ext | MIME | Renderer | Kind |
|---|--------|-----|------|----------|------|
| 1 | PDF Document | `.pdf` | `application/pdf` | jsPDF | binary |
| 2 | Microsoft Word | `.docx` | `application/vnd.openxmlformats-officedocument.wordprocessingml.document` | docx | binary |
| 3 | Markdown | `.md` | `text/markdown` | string | text |
| 4 | HTML Page | `.html` | `text/html` | string | text |
| 5 | Plain Text | `.txt` | `text/plain` | string | text |
| 6 | Rich Text | `.rtf` | `application/rtf` | string | text |

## Descriptions & recommended use (as shown in the modal)

- **PDF** — Branded, print-ready, fixed-layout document. *Best for: sharing with
  clients, printing, and archiving.*
- **Word (.docx)** — Fully editable Word document with styles and tables.
  *Best for: editing, adding notes, and collaborative review.*
- **Markdown (.md)** — Lightweight plain-text markup with headings and tables.
  *Best for: docs, wikis, GitHub, and static site publishing.*
- **HTML** — Self-contained styled web page with inline branding. *Best for: web
  embedding, email, and browser viewing.*
- **Plain Text (.txt)** — Universal unformatted text; opens anywhere. *Best for:
  maximum compatibility and quick reading.*
- **Rich Text (.rtf)** — Portable formatted document for any word processor.
  *Best for: opening in Word, Pages, or WordPad without conversion.*

## What every export contains

Built from the canonical model, so identical across formats:

1. **Narratix Lab branding** (header + footer)
2. **Report title** (`Niche · Platform`)
3. **Generation date**
4. **Script name**, **Platform**, **Niche**, **Goal**
5. **Overall score** + verdict
6. **Module scores** (Hook, Retention, Script, Editing, Emotion, Growth)
7. **Benchmarks** (scroll-stop, swipe-away, completion, structure/clarity/authority, viral trigger)
8. **Evidence** (detected hook/CTA, hook type & failure reason, consultant summary)
9. **Detailed module analysis** (strengths / weaknesses / recommendations / priority fixes per module)
10. **Recommendations** (aggregated list)
11. **Action plan** (ordered priority fixes + growth checklist / demo next-steps)
12. **Confidence & metadata** (detection confidence, content type, audience, funnel stage, word count, reading time)
13. **Demo badge** (when applicable)
14. **Transparency footer** (demo disclaimer OR live provenance — see 04)

## Format-specific presentation notes

- **PDF** — brand-red header rule, overall-score card, per-page footer
  (`Generated by Narratix Lab` + page N/M), automatic pagination via `ensure()`.
- **DOCX** — centred branded title block, module-score table with light borders,
  Heading 2 sections, bulleted/numbered lists, italic footer. Fully editable.
- **HTML** — one self-contained file (inline CSS, no external requests),
  print-friendly `@media print`, key-value grid, score card.
- **RTF** — RTF 1.x with a colour table (brand red / muted grey); non-ASCII is
  escaped to `\uN?` for portability across Word / Pages / WordPad / TextEdit.
- **Markdown** — GitHub-flavoured: `#`/`##` headings, pipe tables, task-style
  and ordered lists, `>` callout for the transparency notice.
- **Plain Text** — rule-underlined headings, aligned key/value columns, `•` and
  numbered lists; opens identically everywhere.

## Extensible for the future

ODT and EPUB can be added as renderer #7 and #8 by registering one entry each in
`renderers/index.ts` — no change to the model, builder, service, or modal.
