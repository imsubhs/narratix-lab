# Stage 8B — Demo Transparency & Privacy

Every export carries an honest transparency footer, and no export ever leaks
internal telemetry. Both rules are enforced in one place — `buildReportModel()` —
so they hold identically across all six formats.

## Demo vs live detection

The builder reads only provenance-safe fields already attached to the result:

```ts
const source = meta.generation_source ?? meta.generationSource; // snake (stored) / camel (fresh)
const isDemo = source === 'demo' || !!result.demo;
```

## DEMO_MODE = true

`transparency.isDemo = true`, a **Demonstration Mode** badge is shown, and every
export appends the mandated sentence verbatim:

> This report was generated in Narratix Lab Demonstration Mode. Measured metrics
> reflect the uploaded script while strategic insights come from validated
> demonstration profiles.

(exported as the constant `DEMO_DISCLAIMER`). The demonstration profile label is
included when present. **No provider/model is shown** — a demo report is never
dressed up as a live generation.

## DEMO_MODE = false (live)

The footer reads **"Generated by Narratix Intelligence Engine"** followed by
provenance pairs:

| Label | Source field |
|-------|--------------|
| Provider | `meta.provider` |
| Model | `meta.model` |
| Prompt Version | `meta.prompt_version` |
| Analysis Version | `meta.analysis_version` |

These four are provenance, not telemetry, and are intentionally the only meta
fields any export reveals.

## DO NOT EXPORT — enforced

The builder never reads these fields, which is the only path any format can
take. They exist on `meta` but are ignored:

- Internal request IDs (`request_id`)
- Provider latency (`latency_ms`)
- Telemetry (any `ai_*` event data)
- Token counts (`prompt_tokens`, `completion_tokens`)
- API cost (`estimated_cost_usd`)
- Secrets / API keys (never present in results in the first place)

### Verification

`scripts/export-tests.ts` builds a synthetic **live** report whose `meta`
deliberately includes `request_id: "req_SECRET_12345"`, `latency_ms: 8123`,
`prompt_tokens: 4096`, `completion_tokens: 2048`, and
`estimated_cost_usd: 0.1234`, renders **all six formats**, and asserts that none
of those tokens (nor their camelCase variants, nor their literal numeric values)
appear in any output. The PDF byte stream is scanned for the secret request id
too. All 15 forbidden-field assertions pass.

The demo path is verified independently: the exported Markdown contains the exact
`DEMO_DISCLAIMER` sentence and contains no live provider/model string.
